# Relievo 睿舒智慧 · 服務業預約排程與智慧派工雲端平台 (宣傳官網與多系統矩陣)

Relievo 官方行銷宣傳官網與多產業 SaaS 解決方案矩陣中心。

---

## 🌟 亮點功能

1. **產品核心宣傳 (Flagship Showcase)**：
   - 聚焦宣傳 **Relievo Spa 按摩養生館旗艦排程系統**
   - 內建 **沙盒互動排程模擬器 (Interactive Live Scheduler Sandbox)**，訪客可在首頁即時感受多約束滿足演算法
   - 效益計算機 (ROI Calculator) 與真實客戶評價

2. **多產業擴充矩陣 (Multi-System Solutions Matrix)**：
   - 💆 **Relievo Spa**（按摩養生館智慧排程 - *旗艦版已上線*）
   - 💅 **Relievo Beauty**（美容美甲美睫沙龍 - *即將推出 / 早鳥預約*）
   - 🧘 **Relievo Studio**（瑜珈健身團課私教 - *擴充規劃中*）

3. **名單捕獲與表單驗證 (Lead Generation)**：
   - 支援 14 天免費試用與專人 1 對 1 線上演示預約表單，具備繁體中文與台灣手機號碼格式驗證。
   - 整合一鍵直達線上 Demo 系統 (`http://localhost:5173`)。
